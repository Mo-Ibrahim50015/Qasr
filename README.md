# قصر العطور (Qasr Al Otoor) — Luxury E-Commerce Platform

> **المتجر الرسمي لعلامة قصر العطور في جمهورية مصر العربية**  
> متجر إلكتروني متكامل بالعربية وبواجهة RTL فاخرة، متخصص في العود الملكي، المسك، العنبر، وأرقى العطور الشرقية والفرنسية، مع دعم الدفع عند الاستلام (COD) والدفع الإلكتروني عبر Paymob.

## 🛠 البنية التقنية (Tech Stack)

- **الواجهة الأمامية (Frontend):** Next.js 14 (App Router) + TypeScript + Tailwind CSS (RTL + خط Cairo الفاخر) + Lucide Icons.
- **الواجهة الخلفية (Backend API):** Node.js + Express + TypeScript + Prisma ORM.
- **قواعد البيانات والتخزين المؤقت:** PostgreSQL 16 + Redis 7 (مع fallback داخلي مرن).
- **التخزين السحابي للصور:** Cloudflare R2 Object Storage عبر نطاق مخصص.
- **الحماية والشبكة:** Cloudflare CDN, DNS, WAF (TLS 1.3 Strict) + Nginx Reverse Proxy.
- **الحاويات والتشغيل:** Docker Compose على خادم VPS (Ubuntu 24.04 LTS).

## 🚀 التشغيل السريع (Quick Start)

### 1. تشغيل بيئة التطوير عبر Docker Compose
```bash
docker compose up --build -d
```
الخدمات ستكون متاحة على:
- واجهة المتجر: `http://localhost:3000`
- لوحة الإدارة: `http://localhost:3000/admin`
- واجهة الـ API: `http://localhost:5000/api/v1`
- فحص الحالة: `http://localhost:5000/health`

### 2. بيانات الدخول الافتراضية للمدير (Admin)
- البريد الإلكتروني: `admin@qasralotoor.com`
- كلمة المرور: `Admin@Qasr2026`
- الصلاحيات: مدير النظام (Full Access)

## 🔒 الأمان وحماية البيانات
- كلمات المرور مشفرة بواسطة `bcrypt` (معامل تكلفة 12).
- تشفير بيانات الاتصال عبر `TLS 1.3`.
- التحقق من مدخلات أرقام الهواتف المصرية بنمط `01X XXXXXXXX`.
- التوافق مع قانون حماية البيانات الشخصية المصري رقم 151 لسنة 2020.
